## How to Publish on Netlify (30 Seconds)
1. Go to **https://app.netlify.com/drop** (log in with your free Netlify account).
2. Drag and drop this entire ZIP file (`Adiyans-Overseas-Netlify-Package.zip`) onto the Netlify Drop box.
3. Your site will go live immediately with free HTTPS SSL!
4. Any form submissions on the website will appear automatically in your Netlify Dashboard under **Forms -> consultation-inquiry**.
